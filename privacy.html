Privacy Policy – Sanatan Uploader

Last updated: 31 October 2026

Sanatan Uploader is a private tool used only by the owner of the YouTube channel Sanatan Beats to upload and schedule that channel's own videos.

What data is used

The tool uses Google OAuth access granted by the channel owner to the YouTube Data API (scope youtube.force-ssl) to upload videos, set thumbnails, add videos to playlists and post comments on the owner's own channel.

What is stored

The OAuth credentials are stored only as encrypted secrets in the owner's private GitHub repository. Uploaded video IDs are recorded in that private repository. No personal data of any other person is collected, stored, sold or shared.

Use of Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool is also bound by the YouTube API Services Terms of Service and the Google Privacy Policy (https://policies.google.com/privacy).

Revoking access

The owner can revoke access at any time at https://myaccount.google.com/permissions.
